Intermediate Pathway Analysis

This application reconstructs three-step causal pathways connecting two gene sets through statistically enriched intermediate regulators, using INDRA CoGEx, an automatically assembled biomedical knowledge graph. Given an upstream gene set and a downstream gene set, the application identifies intermediate regulators statistically enriched in both directions, assembles three-step paths (upstream gene → intermediate → downstream gene), and scores them by a normalized product of enrichment strength and effect sizes from both datasets.

Upload two files containing your upstream and downstream gene sets. Each file must contain a column with gene symbols and a column with a ranking metric. Metric values will be scaled to [0, 1] so that upstream and downstream scores are comparable regardless of their original units.

Example dataset:
AZD5363 (capivasertib, pan-AKT inhibitor)
download upstream file (gene column: gene, metric column: EC50, invert metric: ✓)
download downstream file (gene column: gene, metric column: log2FC).
